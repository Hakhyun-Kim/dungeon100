# 리소스 대장 (Assets & Licenses)

이 게임에 들어간 **모든 외부 요소**의 출처·라이선스를 한곳에 기록한다.

> **원본은 이 문서가 아니라 [`docs/assets.json`](assets.json)이다.** 아래 표는 거기서 생성된다
> (`npm run assets-write`). 손으로 쓴 표는 반드시 낡기 때문에, 고칠 때는 JSON만 고친다.
>
> 그리고 이 문서는 장식이 아니다 — `npm run assets-check`가 **원장과 실제 코드를 매번 대조**하고
> 배포 게이트에 걸려 있다. 원장에 없는 리소스 파일·외부 호스트가 런타임에 섞여 들면 배포가 멈춘다.

## 반입 규칙 (2026-07-27 개정)

예전 규칙은 **외부 에셋 전면 금지**였다. 이제는 **라이선스가 허용하면 외부 리소스도 쓸 수 있다.**
바뀐 건 금지의 유무가 아니라 방향이다 — 금지가 아니라 **원장 없는 반입 금지**.

**왜 여전히 절차 생성이 기본인가**: 복잡성이 파일이 아니라 코드에 있어야 AI가 읽고 고치고
검증할 수 있다. 이 프로젝트의 자동화(밸런스 봇·스모크·야간 회귀)가 성립하는 이유가 그것이다.
그리고 절차 생성이 *이기는* 자리가 따로 있다 — 끝나지 않는 BGM, 층마다 달라지는 지형처럼
파일로 바꾸면 오히려 잃는 것들. 바이너리가 늘수록 "AI가 자기 게임을 고칠 수 있는 범위"가 준다.

### 3단 사다리 — 위에서부터 시도한다

| 단계 | 형태 | 예 | 이 저장소의 현황 |
|---|---|---|---|
| **① 절차 생성 (기본)** | 코드로 만든다 | 지오메트리·캔버스 텍스처·Web Audio 합성음 | 그래픽·사운드 전부 |
| **② 참조/규격만 반입** | 원본 파일은 저장소에 안 들인다 | CDN 웹폰트, 공개 규격·수치를 코드로 재생성 | 웹폰트 1건 |
| **③ 원본 파일 반입 (최후)** | png·mp3·glb 등을 저장소에 넣는다 | 절차 생성으로 도저히 대체 불가할 때만 | **0건** |

**③은 최대한 자제한다.** 쓰더라도 원장의 `why`에 "이건 왜 코드로 못 만드는가"를 남긴다
(비어 있으면 검사가 실패한다).

### 종류별 정책

| 종류 | 정책 | 이유 |
|---|---|---|
| **폰트** | 허용 — OFL/CC0만, **시스템 폰트 폴백 필수** | 가장 값싸게 완성도가 오른다. 대체 가능해 위험이 낮다 |
| **그래픽** | 허용하되 **스타일 통일이 라이선스보다 먼저** | 톤이 다른 소스를 섞으면 오히려 조잡해진다 |
| **사운드** | **BGM은 합성 유지**, 단발 실물 소리(발소리·문·묵직한 타격)는 반입 가능 | 합성이 약한 자리가 정확히 거기다. 배경음은 합성이어야 상황별 변주가 공짜 |

### 라이선스 게이트 (②③ 공통 — 하나라도 불확실하면 반입하지 않는다)

- [ ] **출처가 1차 원본인가** — 재업로드 사이트가 아니라 원 배포처
- [ ] **라이선스가 명시돼 있는가** — "무료"는 라이선스가 아니다. OFL/CC/MIT/CC0처럼 이름이 있어야 한다
- [ ] **공개 배포·상업적 사용이 허용되는가** — 이 저장소는 **공개**이고 GitHub Pages로 배포된다
- [ ] **귀속(attribution) 요건을 지킬 수 있는가** — 필요하면 원장 + 게임 내 크레딧에 표기
- [ ] **파생·개작이 허용되는가** — 색·크기·자르기 없이 쓰는 경우는 드물다
- [ ] **NC(비상업)·ND(변경금지)가 아닌가** — 이 둘은 원칙적으로 반입 금지

### 반입 후 지켜야 할 것

- **원본 그대로 둔다.** 게인·피치·필터·색조 같은 손질은 코드에서 한다 — 파일을 건드리면
  "정말 그 출처에서 왔는가"를 더는 대조할 수 없다.
- **없으면 없는 대로 서게 한다.** 반입한 것은 404·오프라인·차단으로 언제든 사라진다.
  소리는 합성음으로, 질감은 색만으로, 글자꼴은 시스템 폰트로 **조용히** 내려가야 한다.
  (실제로 웹폰트 CDN이 막힌 CI 샌드박스에서 이 폴백이 값을 했다.)

## 갱신 방법

1. [`docs/assets.json`](assets.json)의 `hosts` / `files`를 고친다 — 여기가 원본이다.
   - `hosts`: `{host, use, license, source, form, fallback}`
   - `files`: `{path, use, license, source, why}` — `why`는 **절차 생성으로 대체할 수 없는 이유**
2. 표를 다시 쓴다:
   ```bash
   npm run assets-write
   ```
3. 커밋 전에 확인한다 (배포 게이트와 같은 검사):
   ```bash
   npm run assets-check
   ```

라이브러리 표는 손댈 필요가 없다 — `node_modules`의 package.json에서 매번 실측해 다시 쓴다.
